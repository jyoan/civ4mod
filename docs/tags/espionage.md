# 諜報任務のタグ

`CIV4EspionageMissionInfo.xml` は BtS のものを Mod に入れた（Schema は `GameInfo\CIV4GameInfoSchema.xml`）。志向側にはタグを持たせず、任務の側で志向を指定する。効果を強めた任務は、強めた値の任務を別に足して `PrereqTrait` で使えるようにし、元の任務を `DisableTrait` で使えなくする（例: 検証用の `ESPIONAGEMISSION_TEST_CITY_POISON_WATER`）。

| ファイル | タグ | 内容 |
|---|---|---|
| `CIV4EspionageMissionInfo.xml` | `EspionageMissionInfo/PrereqTrait`・`DisableTrait` | `PrereqTrait` の志向を持つプレイヤーだけがその任務を使える。`DisableTrait` の志向を持つプレイヤーはその任務を使えない。どちらも志向 1 つ（省略・`NONE` で制限なし）。判定は `CvPlayer::isEspionageMissionAllowed`。`CvPlayer::getEspionageMissionBaseCost` が -1（無効）を返すので、スパイの任務の一覧・諜報顧問の費用・AI のどれにも効く（諜報顧問の一覧には費用なしの行として残る。BtS で `iCost` が -1 でない任務は一覧に出るため）。志向は諜報任務より先に読み込まれるので `read` で番号に変える。志向の説明文に、その志向が `PrereqTrait` の任務を `TXT_KEY_TRAIT_ENABLED_ESPIONAGE_MISSIONS`（「使える諜報任務: 水源への毒混入（検証用）, …」）、`DisableTrait` の任務を `TXT_KEY_TRAIT_DISABLED_ESPIONAGE_MISSIONS`（「使えない諜報任務: 水源への毒混入, …」）で出す。諜報任務は `LoadPostMenuGlobals`（ゲームを始めるとき）で読み込まれるので、文明選択の画面など、ゲームの前の説明文には出ない。Python は `CyPlayer.isEspionageMissionAllowed(eMission)`（任務のタグは Python に公開していない） |
| `CIV4EspionageMissionInfo.xml` | `EspionageMissionInfo/bKillGreatPerson`・`bKidnapGreatPerson` | 都市に定住した偉人を 1 人取り除く（`bKillGreatPerson`。任務 `ESPIONAGEMISSION_KILL_GREAT_PERSON`「要人の殺害」）。`bKidnapGreatPerson` はさらに、その偉人のユニットを任務を行ったプレイヤーの首都に作る（任務 `ESPIONAGEMISSION_KIDNAP_GREAT_PERSON`「要人の誘拐」）。`bIsTwoPhases` を `1` にすると、建物破壊と同じ標的選択の画面で偉人の種類を選べる（ボタンは種類ごとに「大科学者 x2 (費用)」。ランダムではない）。定住偉人は、偉人ユニットが定住する専門家（ユニットクラスの既定ユニットの `GreatPeoples` にある専門家）の無料の専門家のうち、建物が与える分を除いた数（BtS の `CvCity::getAddedFreeSpecialistCount`。イベントで得た偉人の専門家も含む）。誘拐で作るユニットは、そのプレイヤーの文明・志向の固有ユニットを含めた、その専門家に定住するユニットクラスのユニット（`CvPlayer::getGreatPersonUnit`）。首都がなければ誘拐はできない。必要 EP は `iCost`（費用の係数を持たない BtS の任務と同じく、ゲーム速度の研究の補正をかける。距離・諜報への防御などの補正も BtS どおり）。足した 2 つの任務は `iCost` 500・800、`iDifficultyMod` 25・50、`PrereqTrait` なし（誰でも使える）。メッセージ: 相手に `TXT_KEY_ESPIONAGE_TARGET_GREAT_PERSON_KILLED` / `_KIDNAPPED`、誘拐した側に `TXT_KEY_ESPIONAGE_GREAT_PERSON_KIDNAPPED_TO`。費用のツールチップ `TXT_KEY_ESPIONAGE_HELP_KILL_GREAT_PERSON` / `_KIDNAP_GREAT_PERSON`。AI は使わない（`AI_espionageVal` が 0）。Python は `CyPlayer.getGreatPersonUnit(eSpecialist)` |
